## Названия команд

> Открывается по кнопке «Продолжить» на [Выборе игроков](#выбор-игроков), если включён командный режим.

Модель хранения (`players` / `teams` / `currentGame`) — в [tech.md](./tech.md). В `currentGame` поле `gameStarted` отмечает, что партия уже начата: заданы состав, козырь и раздающий. Пока оно `false`, козырь, раздающий и счёт пустые. Сформированные команды (обе id в `currentTeamIds`) или `gameStarted: true` означают, что удаление выбранного игрока сбрасывает сессию, а не только снимает галочку.

  - **Имя команды красных** — обычный `Input`; подпись «Имя команды красных»; в скобках рядом с подписью — имена игроков этой команды
- [x] Состав команд по порядковым номерам выбора (через одного, не соседи): **чёрные — №1 и №3**, **красные — №2 и №4**

- после [Названия команд](#названия-команд), если включён командный режим;

Если выбрано меньше двух игроков, нет раздающего или в командном режиме не заданы обе команды, экран не показывается: тихий переход на [Выбор игроков](#выбор-игроков) без сброса сессии. ## Завершение раунда

> Открывается с [главного экрана игры](#главный-экран-игры) по кнопке «Завершить раунд» после подтверждения в диалоге. Это же страница завершает партию, если кто-то набрал `>= 12` очков. Отдельного экрана `/game-end` нет. Игровая механика штрафных очков и «яиц» — в [правилах «Буркозёл»](./bkozel-rules.md#подсчёт-взяток-и-начисление-штрафных-очков).

В командном режиме на экране две команды, счёт хранится по `teamId`. Без команд — игроки, счёт по `playerId`. Отдельного счёта у игроков одной команды нет. Нет ключа в `scores` — на экране `0`.

### Приоритет 1

- [x] Заголовок «Штрафные очки за раунд». Режим заполнения один на весь список: старт — радиокнопки `0, 2, 4, 6, 8, 12` (изначально выбрано `0`). Кнопка в шапке переключает на ввод числом и обратно; переключение сбрасывает штрафные в `0` и не сбрасывает уже выбранный козырь
- [x] Список команд (в командном режиме) или игроков (без команд); подпись — имя и сумма текущих очков плюс выбранные штрафные. При сумме `>= 12` подпись подсвечивается
- [x] Штрафные за раунд выбираются для каждой стороны. Значение `> 0` можно указать **только у одной** стороны — иначе явная валидация не даёт отправить форму. Все `0` допустимы («яйца»). Числовой ввод: любое целое от `0`; пустое поле считается `0`; дробь и отрицательное число видны в сумме, пока набраны, но отправку не проходят (ошибка «Введите целое число от 0»)
- [x] Если никто не набрал `>= 12` очков (текущие + штрафные): виден выбор следующего козыря и кнопка «Продолжить». Штраф `> 0` записывается в ключ стороны в `scores`; козырь обновляется; раздача переходит к следующему игроку по `selectedPlayerIds`; переход на `/game`. Если у всех `0` — меняются только козырь и раздающий
- [x] Если хотя бы одна сторона набрала `>= 12`: блок козыря скрыт, кнопка «Закончить» сбрасывает только `currentGame` и открывает `/` (последние сыгранные игры на главной — приоритет 2)

### Приоритет 2

- Законченные игры сохраняются
