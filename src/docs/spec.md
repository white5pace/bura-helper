### Приоритет 1

- [x] Два поля ввода — по одному на каждую команду:
  - **Имя команды чёрных** — обычный `Input`; подпись «Имя команды чёрных»; в скобках рядом с подписью — имена игроков этой команды
  - **Имя команды красных** — обычный `Input`; подпись «Имя команды красных»; в скобках рядом с подписью — имена игроков этой команды

- [x] Валидация: имя команды — минимум 3 символа (для обоих полей)
- [x] По кнопке «Продолжить» обновляются имена команд и переход на [Подготовку к игре](#подготовка-к-игре)

> Открывается по кнопке «Начать игру» на [Подготовке к игре](#подготовка-к-игре).

### Приоритет 1

- [ ] По углам экрана — карточки команд или игроков, прижатые к каждому углу

  - Комбинации

### Неопределённый приоритет

- Режим главного экрана для одного игрока или для режима «друг напротив друга»

## Завершение раунда

### Приоритет 1

- [ ] Выбор проигравшей команды или ничьей
- [ ] Выбор штрафных очков **или** ввод числа очков на каждого
  - _Заметка:_ отображение на троих и четверых без команды пока не продумано
  - _Решение:_ выводим список игроков или команд; справа — тогл «очки» / «штрафные очки» (приоритет — штрафные, так проще); радио-кнопки: 0, 2, 4, 6
- [ ] Если команда набрала ≥ 12 очков → игра заканчивается и удаляется из истории
- [ ] Кнопка «Начать новую игру»
