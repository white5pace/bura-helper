# Выбор игроков

## Приоритет 1

- Список всех игроков
- Добавление нового игрока
- Выбор игроков чекбоксом
- Редактирование имени игрока
- При выборе возле имени появляется порядковый номер (1, 2, 3, 4)
- В командном режиме фон чекбоксов отражает команду:
  - **1-я команда** (игроки с порядковыми номерами 1 и 2) — стандартный **чёрный** фон
  - **2-я команда** (игроки с порядковыми номерами 3 и 4) — **красный** фон
- Сверху switch который называется командный режим и когда он включён у нас справа от этого свитча появляется сколько человек выбрано из четырёх
- Соответственно если выбрано меньше четырёх то у нас на кнопку продолжить идёт валидация где если у нас нету четырёх игроков то возникают тост с ошибкой "Выберите четырёх игроков для командного режима"
- Кнопка «Продолжить» → при включённом командном режиме переход на страницу [Названия команд](./teams.md); иначе — на [Подготовку к игре](./game-start.md)

## Приоритет 2

- Кнопка «Фильтровать выбранных»

## Приоритет 4

- Подсказка для названия команд (например: имя + имя = предмет + прилагательное: Ира + Коля → «Иркутский кол», «Иридивая Кола», «Каловый Ирис»)

## Фантазия

- Развернуть на сервере простую LLM для генерации названий команд по подсказке
