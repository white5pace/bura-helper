# Названия команд

> Открывается по кнопке «Продолжить» на странице [Выбор игроков](./participants.md), если включён командный режим.

## Приоритет 1

- Два поля ввода — по одному на каждую команду:
  - **Имя команды чёрных** — обычный `Input`; подпись «Имя команды чёрных»; в скобках рядом с подписью — имена игроков этой команды
  - **Имя команды красных** — обычный `Input`; подпись «Имя команды красных»; в скобках рядом с подписью — имена игроков этой команды
- Предзаполнение каждого поля: имя первого игрока команды + имя второго игрока команды (без разделителя)
- Валидация: имя команды — минимум 3 символа (для обоих полей)
- Кнопка «Продолжить» внизу страницы → переход на [Подготовку к игре](./game-start.md)
