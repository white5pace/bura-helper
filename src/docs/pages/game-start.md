# Подготовка к игре

> Последний экран перед [главным экраном игры](./game.md).

**Когда открывается:**

- после [Названия команд](./teams.md), если включён командный режим;
- после [Выбор игроков](./participants.md), если командный режим выключен.

## Приоритет 1

- Отображение, кто сейчас раздаёт: первый игрок (по порядку выбора на странице участников)
- Выбор козыря для предстоящего раунда (радиокнопки)
- Кнопка «Начать игру» внизу страницы → переход на [главный экран игры](./game.md)
