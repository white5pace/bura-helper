# Главный экран игры

> Открывается по кнопке «Начать игру» на странице [Подготовка к игре](./game-start.md).

- По углам экрана — карточки команд или игроков, прижатые к каждому углу
- На карточках: имя игрока и его счёт; если игрок в команде — надпись команды
- Рядом с именем иконка, если игрок раздаёт или раздавал в этом раунде
- Для игроков напротив — карточка перевёрнута
- По центру:
  - Козырь
- Кнопка «Завершить раунд»

## Приоритет 3

- Подсказка
- Подсчёт очков:
  - Карта и её стоимость в очках
  - Индивидуальный подсчёт очков под количество игроков (на 2, 4, 6)
  - Комбинации

## Неопределённый приоритет

- Режим главного экрана для одного игрока или для режима «друг напротив друга»
